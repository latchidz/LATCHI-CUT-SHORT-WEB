# LATCHI CUT SHORT — Landing Page
صفحة هبوط احترافية (عربية RTL) لتطبيق LATCHI CUT SHORT — ملف واحد `index.html` بدون أي اعتماديات أو بناء.

## النشر على Netlify (أو Vercel) بنفسك — دقيقتان:
1. ادخل https://app.netlify.com → **Add new site → Import an existing project**.
2. اختر هذا المستودع `latchidz/LATCHI-CUT-SHORT-WEB`.
3. اترك حقول البناء فارغة: **Build command: (فارغ)** · **Publish directory: `./` (الجذر)**.
4. Deploy — ستحصل على رابط مباشر فورًا.

على Vercel نفس الخطوات: New Project → Import Repo → Framework: Other → Deploy.
